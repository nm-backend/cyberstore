# CyberStore — интернет-магазин ноутбуков, ПК и комплектующих

Современный интернет-магазин компьютерной техники для **CyberStore** (Бишкек), вдохновлённый эстетикой профиля `@cyberstore_nout`.

Стек: **Django 5.2 · HTML5 · CSS3 (Cyberpunk Dark Neon) · JavaScript · SQLite/PostgreSQL · Render**.

---

## 🚀 Быстрый запуск локально (Windows, Mac, Linux)

```bash
# 1. Клонирование / переход в папку проекта
cd cyberstore

# 2. Создание и активация виртуального окружения
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Mac / Linux:
# source .venv/bin/activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Файл переменных окружения (.env)
# В Windows PowerShell:
Copy-Item .env.example .env
# Либо в bash: cp .env.example .env

# 5. Применение миграций и создание начальных данных
python manage.py migrate

# 6. Создание администратора (логин/пароль из .env; без пароля админ не создаётся)
python manage.py bootstrap_site

# 7. Каталог наполняется через админку /admin/ — демо-товары не входят в репозиторий

# 8. Запуск сервера разработки
python manage.py runserver
```

- **Сайт:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Панель администратора:** [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
  - Логин: `admin`
  - Пароль: `DJANGO_SUPERUSER_PASSWORD` из `.env`
- **Запуск тестов:** `python manage.py test`

## 🛠️ Возможности административной панели

### 1. Добавление готовых компьютеров (ПК) и указание характеристик
- Перейдите в **Каталог → Товары → Добавить**.
- Выберите категорию **«Готовые ПК»** (или «Ноутбуки», «Комплектующие»).
- Укажите название (например, `Игровой ПК Cyber Beast RTX 4070 Ti Super`), цену и гарантию.
- В блоке **Характеристики** выберите из готового списка тип характеристики и введите значение:
  - Процессор: `AMD Ryzen 7 7800X3D`
  - Видеокарта: `NVIDIA GeForce RTX 4070 Ti Super 16GB`
  - Оперативная память: `32 ГБ DDR5 6000 МГц`
  - Накопитель: `2 ТБ SSD M.2 NVMe PCIe 4.0`
  - Материнская плата: `ASUS TUF GAMING B650-PLUS WIFI`
  - Охлаждение: `СЖО 360мм DeepCool LT720 ARGB`
  - Блок питания: `850W 80+ Gold Seasonic Focus`
  - Корпус: `LIAN LI Lancool III RGB со стеклом`
  - Операционная система: `Windows 11 Pro`
- *Нужен новый параметр?* Нажмите зелёный плюс **«+»** прямо рядом с выпадающим списком характеристики и добавьте новый тип на лету (например, «Подсветка» или «Чипсет»).
- **Быстрое создание похожих ПК:** В списке товаров выберите нужный ПК, выберите действие **«Дублировать выбранные товары»** и нажмите **«Выполнить»**. Все характеристики и фотографии скопируются в 1 клик! Вам останется лишь скорректировать видеокарту/процессор и цену.

### 2. Смена адреса магазина при переезде
- Перейдите в **Сайт → Настройки сайта**.
- Поле **«Адрес»**: просто замените текущий адрес (`Айни 31`) на новый (например, `пр. Чуй 142`).
- Нажмите **«Сохранить»**.
- **Всё обновится автоматически:**
  - Шапка сайта и подвал.
  - Страница «Контакты».
  - Интерактивная карта Google Maps (встроенный iframe) автоматически перестроится на новый адрес.
  - Ссылка для открытия навигатора.
  - Поле ссылки на 2GIS (если филиал зарегистрирован в 2GIS).

### 3. Заказ через WhatsApp с автозаполнением
- Когда клиент нажимает кнопку **«Заказать в WhatsApp»** на карточке или странице товара, в WhatsApp автоматически открывается чат с менеджером (`+996220053059`) с готовым текстом:

  💰 Цена: 89 500 сом

### 4. Оформление заявок «Перезвоните мне»
- Если клиент предпочитает звонок, на странице товара есть кнопка **«Оставить заявку, мы перезвоним»**.
- Заявки мгновенно попадают в админку (**Раздел «Заявки»**).
- Можно менять статус заявки прямо в таблице («Новая», «В работе», «Продано», «Отказ») и выгружать заявки в **CSV для Excel**.

## ☁️ Развёртывание на Render (Показ тестового сайта)

В репозитории уже подготовлены файлы конфигурации `render.yaml` и `build.sh`.

### Шаг 1. Загрузите код в GitHub
```bash
git add .
git commit -m "Initial CyberStore release for Render"
# Создайте пустой репозиторий на github.com и привяжите:
git remote add origin https://github.com/<ваш-аккаунт>/cyberstore.git
git branch -M main
git push -u origin main
```

### Шаг 2. Развёртывание через Render Blueprint
1. Зайдите на [render.com](https://render.com) и войдите в аккаунт.
2. Нажмите **New +** → **Blueprint**.
3. Подключите ваш GitHub-репозиторий `cyberstore`.
4. Render автоматически считает конфигурацию из `render.yaml` и создаст:
   - Веб-сервис на Python.
   - Базу данных PostgreSQL (`cyberstore-db`).
5. Render запросит обязательную переменную:
   - `DJANGO_SUPERUSER_PASSWORD` — введите надёжный пароль для администратора сайта (логин по умолчанию `admin`).
6. Нажмите **Apply**. Render выполнит `build.sh`:
   - Установит зависимости (`pip install -r requirements.txt`).
   - Соберёт статику (`collectstatic`).
   - Применит миграции (`migrate`).
   - Автоматически создаст админа (`bootstrap_site`), если заданы логин и пароль.
7. Через пару минут сайт будет доступен по адресу `https://<ваше-имя>.onrender.com`.

### 💡 Постоянное хранение медиа-файлов (Cloudinary)
- Базовый бесплатный тариф Render очищает локальный диск при перезапуске контейнера.
- Для боевого сайта подключите бесплатный аккаунт [cloudinary.com](https://cloudinary.com):
  1. Скопируйте из панели Cloudinary строку `CLOUDINARY_URL` вида:
     `cloudinary://API_KEY:API_SECRET@CLOUD_NAME`
  2. Добавьте эту переменную в **Environment** веб-сервиса на Render.
  3. Все фото и видео, загружаемые через админку, будут сохраняться в облаке навсегда.

## 📂 Архитектура проекта

```text
cyberstore/
├── apps/
│   ├── catalog/              # Каталог: Товары, Категории, Бренды, Характеристики, Фото
│   │   ├── management/       # Служебные команды приложения
│   │   ├── migrations/       # Миграции базы данных
│   │   ├── admin.py          # Настройки админки товаров, фильтры, дублирование
│   │   ├── models.py         # Модели Product, Category, Brand, ProductSpec, SpecType, UseCase
│   │   ├── views.py          # Список товаров, фильтрация по цене/задаче/бренду, детальная страница
│   │   └── urls.py
│   ├── core/                 # Главная страница, условия рассрочки, доставка, контакты
│   │   ├── templatetags/     # Теги: shop_tags (форматирование цен, WhatsApp ссылки)
│   │   ├── models.py         # SiteSettings (адрес, часы, WhatsApp, телефон, слоган)
│   │   ├── admin.py          # Быстрое редактирование настроек сайта
│   │   └── views.py          # Обработчики страниц
│   └── leads/                # Заявки клиентов с сайта
│       ├── models.py         # Модель Lead
│       ├── admin.py          # Управление статусами, экспорт в Excel/CSV
│       └── views.py          # Приём формы заявки
├── config/                   # Конфигурация Django проекта
│   ├── settings.py           # Настройки, WhiteNoise, Cloudinary, БД
│   ├── urls.py               # Главный роутинг
│   └── wsgi.py
├── media/products/           # Фотографии товаров
├── static/                   # Статические файлы (CSS, JS, логотип)
│   ├── css/style.css         # Тёмная кибер-тема
│   ├── js/main.js            # Мобильное меню, галерея фото, модальные окна
│   └── img/                  # Логотип магазина, favicon, соцсети
├── templates/                # HTML шаблоны Django
├── build.sh                  # Скрипт сборки для Render
├── render.yaml               # Инфраструктура как код для Render (Web + Postgres)
├── requirements.txt          # Зависимости Python
└── README.md
```
